# 📊 DataLens — Exploratory Data Analysis App

🔗 **[🚀 Try DataLens Live](https://datalens-eda-app.streamlit.app/)**

An interactive **EDA web application** built with Python and Streamlit to explore, clean, visualize, and export datasets with ease.

### ✨ Features
- 📂 Upload and explore datasets
- 🔍 Analyze columns, statistics, and missing values
- 🧹 Clean data and handle missing values
- 📈 Create interactive data visualizations
- 🔄 Compare original and cleaned datasets
- 📥 Export cleaned data to CSV, Excel, and JSON
